# Contributing

Thanks for your interest.

This repository is a public support shell and does not host active runtime implementation.

## What contributions are welcome here

- Issue reports and troubleshooting details
- Feature requests and workflow suggestions
- Documentation/link corrections for public guidance

## What to avoid here

- Product runtime code changes
- Website runtime implementation changes
- CI/deploy implementation changes

Active implementation happens in the private monorepo. Maintainers will route accepted work internally.
