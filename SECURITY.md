# Security Policy

If you believe you found a security issue, please do not post public exploit details in a public issue.

## Reporting

Open a new issue in this repository titled `Security report: <short summary>` with limited details, and maintainers will follow up with a private channel if needed.

Include:

- affected product (`glider`, `glidermcp-web`, `tsglider`, `glider-memory`)
- affected version
- high-level impact
